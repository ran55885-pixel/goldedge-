# MemeScan — סורק מימקוינים (Solana + Base)

סורק מטבעות חדשים בבורסות מבוזרות, מסנן הונאות, מדרג לפי מומנטום ומבצע **כניסות מדומות (Paper Trading)** כדי למדוד דיוק לפני שמסכנים כסף אמיתי.

## איך זה עובד
1. **גילוי** — מטבעות חדשים וחמים מ-GeckoTerminal ו-DexScreener.
2. **סינון קשיח** — נזילות, שווי (FDV), גיל, נפח, יחס קונים/מוכרים, מומנטום חיובי.
3. **בדיקת הונאות** — Solana: RugCheck (mint/freeze authority, ריכוז ארנקים). Base: GoPlus (honeypot, מס מכירה, בעלים נסתר, mint).
4. **ציון 0-100** — מומנטום, מחזור נפח/נזילות, לחץ קנייה, האצה, גיל, שווי קטן.
5. **מסחר מדומה** — כניסה בציון ≥ 65. יציאה: סטופ לוס ‎-30%, מימוש חצי ב-x2, סטופ נגרר 35% על השאר, יציאה אם הנזילות נשלפה, מקסימום 12 שעות.

## הרצה
```bash
pip install -r requirements.txt
python -m memescan scan          # סריקה אחת, טבלה מדורגת
python -m memescan scan -v       # כולל למה כל מטבע נפסל
python -m memescan run           # רץ ברציפות + מסחר מדומה
python -m memescan stats         # תוצאות: אחוז הצלחה, רווח, הטרייד הכי טוב
python -m unittest discover -s tests
```
כל ההגדרות ב-`config.yaml`. התוצאות נשמרות ב-`data/paper_trades.csv`.

## מצב השקות 🚀 — מטבעות בדקות הראשונות (Solana / pump.fun)
```bash
python -m memescan launch            # רדאר חי + מסחר מדומה
python -m memescan stats --launch    # תוצאות מצב השקות
```
- מקבל **בזמן אמת** כל מטבע חדש שמושק ב-pump.fun (~8 בדקה) וכל מטבע ש"מסיים את העקומה" (graduation) — דרך PumpPortal.
- עוקב אחרי כל מטבע 20 דקות. כל 12 שניות בודק: פי כמה עלה מההשקה, כמה קניות/מכירות ב-5 דק', נפח, האם עדיין עולה.
- **פוסל** מטבע שהמפתח קנה בו יותר מ-8% מההיצע (סכנת זריקה), מטבע שלא עלה לפחות פי 2.5, או שהמוכרים שולטים.
- מחכה 3 דקות מההשקה (בבדיקה חיה, כניסות אחרי דקה נזרקו ב-‎-86%), ודורש שהסטאפ יחזיק בשתי בדיקות רצופות.
- מעל ציון 60 + בדיקת RugCheck → כניסה מדומה. יציאה: ‎-35%, חצי ב-x2, סטופ נגרר 40%, מקסימום 3 שעות.

**שדרוג (מומלץ):** מפתח PumpPortal עם 0.02 SOL פותח זרם של כל עסקה בודדת → ספירת קונים ייחודיים (נגד בוטים שמנפחים) וזיהוי **מכירה של המפתח** (יציאה מיידית). מגדירים: `export MEMESCAN_PUMPPORTAL_KEY=...`

## מודיעין 🛰️: חדשות, רישומים בבורסות וקהילות
```bash
python -m memescan intel             # רץ ברציפות: התראות + למידת אמינות
python -m memescan intel --sources   # טבלת אמינות לכל מקור, לפי תוצאות אמיתיות
```
| רמה | מקורות | מה המשמעות |
|---|---|---|
| בורסה (1.0) | Binance, Coinbase, Upbit, Bithumb: רשימות השווקים והודעות רשמיות | עובדה. רישום חדש הוא הזרז החזק ביותר |
| חדשות (0.85) | CoinDesk, The Block, Decrypt, Blockworks, DL News, Cointelegraph | אמין על עובדות |
| אגרגטור (0.6) | CoinGecko trending, CryptoPanic (מפתח חינמי) | סימן לתשומת לב |
| קהילה (0.3) | Reddit, 4chan /biz/, ערוצי טלגרם ציבוריים | מוקדם אבל רועש ולעיתים ממומן |

- **רישום חדש בבורסה** מזוהה לפי השוואה של רשימת השווקים, ומפעיל התראה מיידית.
- **כתובת חוזה שמוזכרת אצל 2 מקורות בלתי-תלויים או יותר בתוך שעה** מפעילה התראה ומוסיפה נקודות במצב השקות.
- **אמינות נמדדת, לא מוכרזת:** על כל "קריאה" נשמר המחיר באותו רגע, ושוב אחרי שעה ואחרי 24 שעות. כל מקור מקבל ציון EDGE: באיזה אחוז מהמקרים הקריאה הראשונה שלו הובילה לעלייה של 50%+ בשעה או להכפלה ביממה, וגם כמה מהקריאות שלו התרסקו (rug).
- **קבוצות פרטיות:** אפשר רק דרך חשבון הטלגרם שלך, ורק בקבוצות שאתה כבר חבר בהן. ראה את הסקיל memescan-operator.
