# AURUM NEXUS — מערכת מסחר יומי רב-סוכנית לזהב ומט"ח (MT5)

> מסמך זה הוא המדריך המלא בעברית. הקוד, ההערות והשמות בתוכנה באנגלית.

---

## 1. סקירה כללית

Aurum Nexus היא מערכת מסחר **חיצונית** (לא EA בתוך MetaTrader) שמתחברת ל-MetaTrader 5 דרך ספריית ה-Python הרשמית `MetaTrader5`, וסוחרת בזהב (XAUUSD) ובצמדי מט"ח — בכמה חשבונות במקביל.

את העבודה מבצע צוות של **9 בוטים משתפי פעולה**, לכל אחד תפקיד אחד, סטטוס ויומן שמוצגים בדשבורד:

| בוט | תפקיד |
|---|---|
| SCANNER | ניתוח מבנה שוק D1→M1, אזורי היצע/ביקוש, נזילות, Volume Profile, VWAP |
| LEVELS | מפת רמות יומית חיה עם דירוג A+/A/B, מצבי תגובה, ו-DXY |
| SIGNAL | סטאפים על M1/M5/M15 במקביל, אישור בטיים-פריים נמוך, ציון 0–100 |
| RISK (+ Trade Manager) | חישוב לוט, רצפת 1:1, הקטנת גודל, נעילת רווח יומית, יציאות מוקדמות ויעדי זמן |
| EXECUTION | שליחת פקודות, זיהוי מצב מילוי, ניסיונות חוזרים, החלקה |
| GUARDIAN | שומר משמעת עם **זכות וטו** |
| ACCOUNTS | חיבורים, חיבור מחדש, יתרות, השהיה/המשך |
| ANALYST | יומן, סטטיסטיקות, משקלים אדפטיביים, עונתיות |
| STRATEGIST | פרופיל אסטרטגיה לכל סמל, הצעות שינוי ואישורן |

**"אות אחד, ביצוע רבים":** האות מחושב פעם אחת לכל סמל, ומבוצע בכל חשבון פעיל עם גודל פוזיציה משלו; הרמות מותאמות למחיר של כל ברוקר.

עקרונות שלא משתנים:
- **אין הבטחת רווח.** המערכת מבוססת חוקים, שקופה ומדידה; כל החלטה נרשמת עם הסיבה שלה.
- **אין מספרים מומצאים.** כשנתון חסר או ישן מוצג `STALE` / `DISCONNECTED` / `NO DATA` / `n/a`, עם הערך האמיתי האחרון והשעה שלו. נתונים מדומים רק בבדיקות או עם `--simulate`, ותמיד מסומנים `SIMULATED`.
- **ברירת המחדל היא מסחר על נייר (Paper).**
- **רצפות קשיחות** שאף הגדרה, אופטימייזר או סוכן לא יכולים להוריד: יחס סיכוי/סיכון מינימלי 1:1, ציון מינימלי 70, וטו של ה-Guardian.
- **אין ממוצעים נעים בשום מקום** (לא SMA/EMA/WMA או כל פילטר מבוסס ממוצע). בדיקה אוטומטית מכשילה את ה-build אם מופיע כזה. ATR (מדד טווח) מותר.
- **סודות** (סיסמאות MT5, טוקן OANDA, סיסמת הדשבורד) רק ב-`.env` או בהקלדה בזמן ריצה. לעולם לא בקוד, לא ביומנים ולא בקובץ ה-zip.

## 2. אזהרת סיכון (חובה לקרוא)

- מסחר במט"ח ובזהב ממונף מסוכן מאוד. אפשר להפסיד את כל ההון ואף יותר.
- **אין שום הבטחה לרווח.** תוצאות בקטסט, וגם תוצאות עבר אמיתיות, לא מנבאות את העתיד.
- הסדר המומלץ: **Paper ← חשבון דמו (לפחות חודש) ← חשבון אמיתי קטן**, ורק אחרי שהבנת את היומנים והסטטיסטיקות.
- מסחר אמיתי נפתח רק כשכל התנאים מתקיימים יחד (ראה סעיף 5.3), כולל הקלדת המשפט `I UNDERSTAND`.
- על נתוני "Fallback" ציבוריים המערכת **מסרבת** לסחור באמת. זו הגנה קשיחה שנבדקת בטסטים.

## 3. דרישות

- **מחשב Windows או VPS עם Windows שדולק כל הזמן** (ספריית MetaTrader5 עובדת רק ב-Windows).
- Python 3.11 ומעלה, 64-bit (לא נדרש אם משתמשים בקובץ ההתקנה).
- **התקנת MT5 ניידת (portable) נפרדת לכל חשבון.** הספרייה תומכת בטרמינל אחד לכל תהליך, ולכן כל חשבון רץ בתהליך Worker משלו:
  1. מתקינים MT5 פעם אחת.
  2. מעתיקים את כל תיקיית ההתקנה לכל חשבון, למשל `C:\MT5\icm-demo\`, `C:\MT5\pepper-real\`.
  3. מריצים כל עותק פעם אחת עם `terminal64.exe /portable`, מתחברים לחשבון ומסמנים "Algo Trading".
- חיבור אינטרנט יציב. ממשק הדשבורד עובד גם בלי אינטרנט (כל הפונטים והספריות מצורפים).

## 4. התקנה

### 4.1 קובץ התקנה (מומלץ)
1. בונים פעם אחת עם `build_windows.bat`. נוצרים `build\out\dist\Aurum Nexus\Aurum Nexus.exe`, ואם Inno Setup 6 מותקן גם `build\out\AurumNexusSetup.exe`.
2. מריצים את `AurumNexusSetup.exe`. ההתקנה היא למשתמש בלבד, בלי הרשאות מנהל, ויוצרת קיצור דרך בשולחן העבודה ובתפריט התחל עם האייקון הזהוב.
3. בתיקיית ההתקנה מעתיקים `.env.example` ל-`.env` וממלאים (סעיף 5.2).
4. מעתיקים `config\accounts.example.yaml` ל-`config\accounts.yaml` ומתאימים (סעיף 5.1).
5. מפעילים את **Aurum Nexus** מהקיצור. נפתח חלון משלו עם הדשבורד, ואייקון במגש המערכת.

### 4.2 התקנה ידנית (מקוד)
```bat
cd aurum-nexus
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
copy config\accounts.example.yaml config\accounts.yaml
.venv\Scripts\python -m aurum_nexus check --network
run_app.bat            :: חלון משלו + אייקון מגש
run.bat                :: או בדפדפן
run_demo.bat           :: דמו: חשבונות נייר על נתונים ציבוריים (בלי MT5)
```
חלופה לקיצורי דרך בלי מתקין: `powershell -ExecutionPolicy Bypass -File .\create_shortcut.ps1`.

### 4.3 תפריט מגש המערכת
Open Dashboard · Phone/LAN QR · Pause All · Resume All · Kill Switch · Settings folder · Autostart (הפעלה עם Windows) · Quit.

### 4.4 פקודות CLI
| פקודה | מה היא עושה |
|---|---|
| `mt5sys run` | מפעיל Hub, Workers ודשבורד (`--simulate`, `--yes-live`, `--price-source`, `--port`) |
| `mt5sys check` | בודק הגדרות, רצפות, טרמינלים ו-.env (`--network` בודק גם מקורות מחיר) |
| `mt5sys backtest` | מריץ את אותו צינור בדיוק על היסטוריית M1 |
| `mt5sys optimize --symbol X` | אופטימיזציית Walk-forward, מייצר פרופיל מוצע ודו"ח |
| `mt5sys download-history` | מוריד היסטוריית M1 (מ-mt5, oanda או yahoo) |

(בלי התקנת package: `python -m aurum_nexus <command>`.)

## 5. הגדרות: accounts.yaml, ‏.env ו-system.yaml

### 5.1 `config/accounts.yaml`: כל שדה
| שדה | הסבר |
|---|---|
| `name` | שם ייחודי שמוצג בדשבורד |
| `kind` | `mt5` (טרמינל אמיתי) או `paper_only` (נייר בלבד על מחירי הפיד) |
| `login`, `server` | מספר החשבון ושם השרת כפי שמופיעים ב-MT5 |
| `terminal_path` | נתיב ל-`terminal64.exe` של העותק הנייד **של החשבון הזה** |
| `password_env` | **שם** המשתנה ב-`.env` שמחזיק את הסיסמה (הסיסמה עצמה לא נכתבת כאן) |
| `server_utc_offset_hours` | הפרש שעון השרת מ-UTC (אצל רוב הברוקרים 2 בחורף ו-3 בקיץ) |
| `mode` | `paper` או `live` |
| `allow_live` | חייב להיות `true` כדי שהחשבון יוכל לסחור באמת |
| `allow_real` | נדרש בנוסף לחשבון **אמיתי** (לא דמו) |
| `risk_pct` | אחוז מההון בסיכון לכל עסקה (מקסימום 3; מומלץ 0.25–0.5) |
| `symbols` | רשימת סמלים לחשבון; ריק = כל הסמלים הפעילים |
| `symbol_map` | שמות ברוקר מפורשים, למשל `{XAUUSD: XAUUSD.m}` (בדרך כלל מזוהה אוטומטית) |
| `limits` | מגבלות לחשבון: `max_trades_per_day`, `daily_max_loss_pct`, `max_concurrent_positions` |
| `magic` | מספר Magic של המערכת (ברירת מחדל 770077); עסקאות אחרות מסומנות MANUAL/OTHER |
| `enabled` | הפעלה/כיבוי של החשבון |
| `starting_balance`, `currency` | לחשבונות נייר |

**הגדרות מומלצות לדמו:** `mode: paper`, `allow_live: false`, `risk_pct: 0.5`, `limits: {max_trades_per_day: 8, daily_max_loss_pct: 2, max_concurrent_positions: 3}`. אחרי תקופת נייר: `mode: live` + `allow_live: true` **בחשבון דמו בלבד** לחודש לפחות.

### 5.2 `.env`: סודות בלבד
```
MT5_PASSWORD_DEMO1=...        # לפי password_env של כל חשבון
OANDA_TOKEN=...               # מקור מחיר משני (סעיף 7)
OANDA_ACCOUNT_ID=...
OANDA_ENV=practice            # practice | live
DASHBOARD_TOKEN=              # אופציונלי: טוקן API קבוע
DASHBOARD_USER= / DASHBOARD_PASSWORD=   # אופציונלי: יצירת משתמש ראשון אוטומטית
TRADINGVIEW_WEBHOOK_SECRET=   # אופציונלי: התראות TradingView (docs/TRADINGVIEW_WEBHOOK.md)
FRED_API_KEY=                 # אופציונלי (בלעדיו משתמשים ב-CSV הציבורי)
```
הקובץ `.env` לעולם לא נכנס ל-git ולא ל-zip. היומנים מסננים כל ערך סודי.

### 5.3 מתי נפתח מסחר אמיתי?
רק כשכל התנאים מתקיימים **יחד**:
1. `system.mode: live` ב-`config/system.yaml`
2. בחשבון: `mode: live` וגם `allow_live: true`
3. לחשבון אמיתי (REAL) גם `allow_real: true`
4. בהפעלה הקלדת `I UNDERSTAND` (או הדגל `--yes-live`)
5. מקור המחיר אינו Fallback/Preview
6. הטרמינל של החשבון מחובר

אם תנאי כלשהו חסר, החשבון ממשיך ב-Paper, והסיבה מוצגת בכרטיס החשבון.

### 5.4 `config/system.yaml`: עיקר ההגדרות
הקובץ המלא כולל את כל המפתחות עם ערכי ברירת המחדל.
- `system`: `mode`, `price_source` (auto|mt5|oanda|fallback), `analysis_account` (איזה טרמינל משמש לניתוח), `day_boundary` (תחילת יום מסחר: 17:00 ניו-יורק), `stale_after_seconds` (6).
- `symbols`: `enabled`, סיומות ברוקר אפשריות, `levels_round_steps` (המספרים העגולים נגזרים מ-ADR ומהמחיר, אף פעם לא קבועים בקוד), מגבלות חשיפה ל-USD ולמטבע.
- `scanner` / `levels` / `dxy` / `signal`: פרמטרים של הניתוח. `signal.weights` הם משקלי הציון (סכומם 100).
- `risk`: `min_rr` (רצפה ≥1.0), `min_score` (רצפה ≥70), `default_risk_pct`, TP1, הקטנת גודל, נעילת רווח.
- `guardian`: הפסד יומי מקסימלי, מספר עסקאות, תקרת סיכון פתוח (4%), ספרד, הפסדים רצופים, revenge block ועוד.
- `sessions`: חלונות סשן בשעון המקומי של כל שוק (מטפל אוטומטית בשעון קיץ).
- `trade_manager` / `time_targets`: חוקי יציאה מוקדמת ויעדי זמן (סעיף 13).
- `news`, `intel`, `analyst`, `strategist`, `dashboard`, `backtest`.

ערך מתחת לרצפה (למשל `min_rr: 0.8`) **מוחזר אוטומטית לרצפה** עם אזהרה, שמוצגת גם ב-`mt5sys check`.

## 6. מקורות מחיר וסדר עדיפויות

1. **ראשי: מחירי הברוקר ב-MT5.** כל הניתוח, הרמות, כלי הווליום, האותות, הכניסות, ה-SL/TP והמילויים מבוססים עליהם כשחשבון MT5 מחובר. אפשר לבחור איזה טרמינל משמש לניתוח (`analysis_account`, ברירת מחדל: הראשון שמחובר).
2. **משני: OANDA v20** (סטרים מחירים, נרות M1 עד D, practice ו-live). אלה אותם מחירים כמו OANDA:XAUUSD ב-TradingView. כששני המקורות קיימים מוצג מדד **"OANDA vs MT5 diff"**.
3. **Fallback (תצוגה בלבד):** ציטוטים ציבוריים חיים (Swissquote) והיסטוריה (Yahoo; זהב מחוזי COMEX מותאם לספוט). מסומן **"PREVIEW ONLY · not for trading · history delayed Xs"**. במצב Live המערכת **מסרבת** לסחור על מקור כזה.

`price_source: auto | mt5 | oanda | fallback`. בכותרת הגרף מוצגים המקור ושעת הטיק האחרון ("last tick 09:40:26 UTC · 0.1s ago").
TradingView לא מספקת API רשמי לנתונים, ולכן **לא מבצעים scraping**. אפשר לחבר התראות Webhook של TradingView כקלט נוסף (docs/TRADINGVIEW_WEBHOOK.md); הן מוסיפות רק הערת ציון קטנה ותחומה, ולעולם לא עסקה בפני עצמן.

## 7. חשבון OANDA Practice וטוקן: שלב אחר שלב

1. נכנסים לאתר OANDA ופותחים חשבון **Practice (דמו)** בחינם. במדינות מסוימות OANDA אינה זמינה; במקרה כזה פשוט מוותרים על המקור המשני.
2. מתחברים ל-**OANDA Hub / My Account** ← **Manage API Access** ← **Generate** טוקן.
3. מעתיקים את ה-**Account ID** (בפורמט `101-004-1234567-001`).
4. ב-`.env`: `OANDA_TOKEN=...`, `OANDA_ACCOUNT_ID=...`, `OANDA_ENV=practice`.
5. מריצים `mt5sys check --network`. אמור להופיע `OANDA: connected`.
6. נתוני סנטימנט (positionBook) זמינים רק לחלק מהטוקנים והמכשירים. אם אין גישה הם מוצגים כ-`n/a` בלי לפגוע בשום דבר.

## 8. תשעת הבוטים בפירוט

### 8.1 SCANNER: ניתוח מבנה (D1/H4/H1 וגם M15/M5/M1)
- מבנה שוק: Swings, ‏HH/HL/LH/LL, ‏**BOS** (שבירה בכיוון המגמה) לעומת **CHoCH** (שינוי אופי), טווח מסחר Premium/Discount.
- אזורי היצע/ביקוש **מנרות סגורים בלבד** (בסיס ואימפולס); ציון לפי טריות, עוצמת יציאה, זמן בבסיס והתלכדות עם טיים-פריים גבוה. אזור פג אחרי 2 נגיעות או סגירה דרכו.
- S/R מקבצי Pivot, ‏PDH/PDL, ‏PWH/PWL, פתיחה יומית, טווח אסיה, מאגרי נזילות (Equal Highs/Lows עם דגל swept), ‏FVG ו-Order Blocks עד מילוי.
- Volume Profile (סשן, יומי, יום קודם, מורכב/שבועי): POC, ‏VAH/VAL (70%), ‏HVN/LVN.
- VWAP יומי/שבועי/מעוגן עם ±1σ/±2σ, ‏ATR regime, ‏ADR ו-ADR used %.
- הסריקה רצה גם על **M15/M5/M1** כדי למצוא יותר הזדמנויות, וכל טיים-פריים מחושב מחדש רק כשנר שלו נסגר.

### 8.2 LEVELS: מפת רמות יומית חיה (מודעת DXY)
- בכל פתיחת יום נבנית מפה (ומתעדכנת חי) מאזורים, PDH/PDL/PWH/PWL, פתיחה יומית, אסיה, POC/VAH/VAL, ‏HVN/LVN, ‏VWAP שבועי ±σ, ‏FVG/OB שלא נבדקו, נזילות ומספרים עגולים.
- רמות קרובות מאוחדות לאזורי התלכדות (ATR×k), מקבלות ציון 0–100 ודירוג **A+/A/B**, ותגובה צפויה (היפוך או פריצה-ובדיקה).
- מכונת מצבים: **WAITING ← WATCHING** (בתוך X·ATR) **← READY** (תגובה חיה תקפה: RVOL, שינוי דלתא, ספיגה, פתיל דחייה, Sweep-and-reclaim) **← BROKEN** (2+ סגירות M5 מעבר לרמה עם ווליום, ותפקיד הרמה מתהפך), ובנוסף **STALLED** כשאין תגובה בזמן. מצב READY מעלה את ציון האות.
- **DXY:** סמל הברוקר אם קיים, אחרת נוסחת ICE סינתטית `DXY = 50.14348112 × EURUSD^-0.576 × USDJPY^0.136 × GBPUSD^-0.119 × USDCAD^0.091 × USDSEK^0.042 × USDCHF^0.036`. ‏EURUSD ו-USDJPY חובה; צמד אופציונלי חסר מושמט, והמדד מסומן "partial". הרמה המוחלטת אז לא זהה לרשמית, אבל הכיוון, המבנה וה-VWAP תקפים.

### 8.3 SIGNAL: הסוחר (M1, ‏M5 ו-M15 במקביל)
ראה סעיף 9.

### 8.4 RISK: מנהל סיכון וגודל פוזיציה
- **לוט** = כסף בסיכון ÷ (מרחק הסטופ בטיקים × ערך טיק). משתמש ב-`trade_tick_value`/`trade_tick_size` של הברוקר ומכבד `volume_min/step/max`. **אף פעם לא מעגל למעלה** מעבר לתקציב; אם התקציב קטן מהלוט המינימלי, העסקה מדולגת. נכון לזהב ולכל צמדי המט"ח.
- סטופ מבני (מעבר לנקודת המבנה) ועוד באפר ATR.
- רצפת 1:1 (סעיף 12).
- יציאות: **TP1** חלקי (50% ב-1R) והזזת הסטופ ל-Breakeven, **TP2** במכשול הנגדי, ו**Runner** עם Trailing לפי מבנה M5.
- הקטנת גודל אחרי הפסדים, בירידה מהשיא ובפילטר עקומת הון (מכפלתי, בלי ממוצעים).
- **נעילת רווח יומית:** עצירה אחרי +3R, או אחרי החזרה של 50% משיא היום.

### 8.5 EXECUTION: שליח הפקודות
`order_send` עם זיהוי מצב מילוי (IOC/FOK/RETURN), ‏Magic, ‏Deviation, וניסיונות חוזרים על requote/timeout. בדיקה מחדש של מחיר, ספרד ו-RR **רגע לפני השליחה ואחרי המילוי** (אם ה-RR ירד מתחת ל-1:1 הפוזיציה נסגרת מיד). כניסות Market או Limit וירטואלי לפי סוג הסטאפ. דחייה (לא ביטול) בשניות הראשונות של נר חדש ובזמן Rollover. החלקה נרשמת לכל עסקה.

### 8.6 GUARDIAN: שומר המשמעת (וטו)
הפסד יומי מקסימלי, מקסימום עסקאות ליום/לסמל/לשעה, מקסימום פוזיציות במקביל, **תקרת סיכון פתוח 4%** (סטאפ בדירוג נמוך יותר מוקטן ל-≥50% או מדולג), מתאם וחשיפה למטבע/USD, ספרד מקסימלי וקפיצת ספרד, שעות סשן, **חדשות** (לוח ForexFactory, אירועי High Impact, X דקות לפני ואחרי, USD לזהב, וגם חלונות ידניים), נעילה ליום אחרי 4 הפסדים רצופים, חסימת "מסחר נקמה" אחרי סטופ, Cooldown, פילטרים לפתיחת יום שני וסגירת שישי, ‏DXY, ‏**Kill switch** גלובלי, וסירוב לסחור Live על נתוני Fallback. נעילה יומית מתאפסת ביום המסחר הבא.

### 8.7 ACCOUNTS: מנהל חשבונות
בריאות חיבור, חיבור מחדש עם Backoff (1, 2, 4… עד 60 שניות), סנכרון יתרה והון, השהיה/המשך לכל חשבון.

### 8.8 ANALYST: מאמן ביצועים
יומן מתויג; סטטיסטיקות לפי סטאפ, סשן, סמל, טיים-פריים וסוג יציאה (Win rate, ‏Expectancy ב-R, ‏Profit factor, ‏Max DD); ביקורת יציאות מוקדמות מול פוזיציית צל. משקל אדפטיבי רק אחרי **15 עסקאות לפחות**, ותחום ל-**±15 נקודות**. סטאפ שלילי באופן עקבי מושבת זמנית ל-**48 שעות** — חוקי בטיחות לעולם לא נוגעים בהם. עונתיות (סמל × סטאפ × שעה × יום) עם כיווץ לממוצע (Shrinkage) ומפת חום. ניטור תדירות הזדמנויות מול יעד של ≥3 ביום לסמל: אחרי 5+ ימים מתחת ליעד המערכת **מציעה** (לא מחילה) הרחבות. איכות לא מורידים בשביל מכסה.

## 10. כלי ווליום, ולמה Tick Volume

במט"ח ובזהב (שוק OTC) **אין ווליום מרכזי אמיתי**. ‏MT5 מספק `tick_volume`, כלומר מספר שינויי מחיר, שנמצא במתאם טוב עם הפעילות. כשהברוקר נותן `real_volume` שאינו אפס, משתמשים בו. לכן **כל כלי הווליום וזרימת ההוראות הם הערכות, ומסומנים ככאלה**:
- דלתא לנר = ווליום × מיקום הסגירה בטווח (או ספירת נרות M1 עולים/יורדים בתוך הנר)
- CVD לסשן, סטיית CVD בנקודות Swing
- RVOL מול אותה שעה ב-N הימים הקודמים
- ספייק/קליימקס, Effort vs Result (ספיגה), ‏VSA (No-demand/No-supply), Stopping volume

מקור בלי ווליום (למשל Fallback של מט"ח) **מכבה את כלי הווליום**, ומקבל ציון ניטרלי-נמוך במקום ציון מומצא.

## 12. כלל 1:1

- RR מינימלי **1.0 הוא רצפה קשיחה**. נמדד מכניסה **ריאלית** (Ask בלונג, Bid בשורט, כולל ספרד) אל הסטופ, ומשם אל **TP1**, **TP סופי** ו**המכשול הנגדי הבא**.
- אם המכשול האמיתי קרוב מ-1R, העסקה **מדולגת**, ואף פעם לא "מותחים" את היעד. ביומן: `SKIPPED RR 0.8 < 1.0`.
- ההגדרה יכולה להעלות את הרצפה, אבל לא להוריד אותה (מוחזר לרצפה עם אזהרה, גם ב-`mt5sys check`).
- נבדק שוב לפני שליחה ואחרי מילוי. TP1 הוא יציאה חלקית מנוהלת, ולכן הוא מחושב מחדש מהכניסה האמיתית כדי שהחלקה לא תוריד אותו מתחת ל-1R. ה-TP הסופי והמכשול **לא זזים**.
- יציאה מוקדמת יכולה להיסגר מתחת ל-1R. הרצפה חלה על כניסות בלבד.

## 13. Trade Manager ויעדי זמן, עם דוגמאות

כל פוזיציה פתוחה נבדקת מחדש בכל מחזור. החוקים, לפי עדיפות (כל אחד ניתן להפעלה/כיבוי):
`friday_close`, ‏`news_ahead`, ‏`end_of_day`, ‏`end_of_session` (כבוי כברירת מחדל), ‏`ltf_choch`, ‏`htf_shift`, ‏`opposing_rejection`, ‏`momentum_fade`, ‏`cvd_divergence`, ‏`vwap_band_rejection`, ‏`dxy_shock`, ‏`giveback`, ‏`spread_spike`, ‏`volatility_spike`.

**דוגמאות מהיומן:**
- `EARLY EXIT XAUUSD +0.6R: opposing CHoCH M5`: אחרי הכניסה הופיע CHoCH נגדי ב-M5, והפוזיציה נסגרה ברווח חלקי.
- `giveback: +0.15R after MFE +1.50R`: העסקה הגיעה ל-+1.5R והחזירה יותר מ-60% מהרווח, ולכן נסגרה.

**יעדי זמן** (`time_targets.enabled`):
- **חלון תגובה ברמה:** אחרי כניסה לאזור צריכה להופיע תגובה תקפה (דחייה, שינוי דלתא, או תנועה ≥ X·ATR) תוך N נרות (ברירת מחדל 3 × M5). אחרת הרמה עוברת ל-**STALLED**: אין כניסה, והציון יורד.
- **שעון התקדמות אחרי כניסה:** צריך להגיע ל-**+0.5R תוך T1** ול-**TP1 תוך T2**. הזמנים נגזרים מקצב ה-ATR/ADR ומהסשן. החמצת T1 מהדקת את הסטופ ל-‎-0.5R (או סוגרת חלקית); החמצת T2 סוגרת.
  - **דוגמה:** זהב, ATR(M5)=2.0$, סיכון 4$. בלונדון הקצב 0.4$ לדקה, כך ש-T1 = 2×(0.5×4)/0.4 = 10 דק' (מינימום 20 ל-M5), ו-T2 = 2×4/0.4 = 20 דק'.
- הדשבורד מציג לכל עסקה **"TP1 ETA 18m · elapsed 7m"** וספירה לאחור של רמות.
- **פוזיציית צל:** אחרי כל יציאה מוקדמת או יציאת זמן ממשיכים לעקוב אחרי מה שהיה קורה לו העסקה הייתה נשארת. ה-Analyst מציג אם היציאה עזרה או עלתה.

   `mt5sys download-history --source mt5 --account icm-demo --symbols XAUUSD,EURUSD,GBPUSD,USDJPY,USDCAD,USDCHF --start 2024-01-01`

2. **בקטסט** (אותו צינור בדיוק כמו ב-Live):
   `mt5sys backtest --csv-dir data\history --symbols XAUUSD,EURUSD,GBPUSD,USDJPY --step 1`
   הדו"ח כולל `equity_curve.png`, ‏`trades.csv` וסטטיסטיקות לפי סטאפ/סשן/סמל/טיים-פריים, עסקאות ליום לכל סמל, פיצול In-sample/Out-of-sample, חלונות Walk-forward, השוואה עם ובלי יעדי זמן וגריד N/T1/T2 קטן, ו**בדיקה שאף עסקה לא נפתחה עם RR מתוכנן מתחת ל-1**. המודל כולל ספרד, עמלה והחלקה, והנחות המסלול בתוך הנר מתועדות בדו"ח.
3. **Walk-forward:** `mt5sys optimize --symbol XAUUSD --csv-dir data\history` כותב פרופיל מוצע ודו"ח, ויוצר הצעה בדשבורד.
4. **חודש על דמו** (`mode: live`, ‏`allow_live: true` בחשבון דמו).
5. **חשבון אמיתי קטן** עם `risk_pct` נמוך (0.25%), ורק אם התוצאות והיומנים הגיוניים.

> `--step 5` מאיץ פי ~5 (מחזור ניתוח כל 5 דקות; ניהול פוזיציות עדיין לכל נר M1).

## 19. מגבלות (בכנות)

- **לא אומת מול טרמינל MT5 אמיתי בסביבת הפיתוח** (Linux, בלי MetaTrader5). מיפוי השדות נבדק מול חיקוי קפדני של הספרייה הרשמית בשמות השדות המתועדים. **חובה להריץ קודם על חשבון דמו.**
- OANDA לא אומת מול חשבון אמיתי (אין טוקן). המימוש נבדק מול תגובות לדוגמה לפי מפרט v20.
- חלון ה-Desktop, מגש המערכת, ה-PyInstaller וה-Inno Setup לא נבנו ולא הורצו בסביבת הפיתוח (נדרש Windows). הקבצים כתובים, אבל הבנייה הראשונה צריכה להתבצע אצלך עם `build_windows.bat`.
- כלי ווליום וזרימה הם **הערכות** מ-Tick volume, לא Order flow אמיתי.
- בבקטסט אין ארכיון חדשות, COT, מאקרו, סנטימנט או DOM היסטוריים, ולכן הפילטרים האלה לא פעילים שם. אין מודל ל-Partial fills ולמגבלות stop-level של ברוקר.
- נתוני Fallback ציבוריים מעוכבים (זהב: חוזי COMEX עם עיכוב של כ-10 דקות, מותאמים לספוט), ומיועדים לתצוגה בלבד.
- DXY סינתטי חלקי (כשחסר צמד) אינו שווה ברמתו למדד הרשמי.
- ביצועי מחזור: ~150–550ms ל-4 סמלים (תלוי במקור הנתונים). בקטסט של חודש עם `--step 1` עשוי לקחת שעות.
- **אין הבטחת רווח. תוצאות בקטסט על נתוני עבר אינן מנבאות את העתיד.**
